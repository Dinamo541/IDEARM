## 4. Editorial criteria and authoritative sources

1. **Intel SDM revision 093:** canonical source for opcode encoding, effects on FLAGS and CPU exceptions.
2. **Irvine (5th edition, Spanish translation):** core teaching reference for x86 Assembly in academic settings.
3. **Stallings (7th edition) and Mano (3rd edition), Spanish translations:** foundations of computer architecture and digital circuits.
4. **Official NASM 3.02, MASM 6.11 and TASM 4.1 manuals:** strict boundaries of each dialect's directives and operators.
5. **Independence from emu8086:** the corpus and the semantic tests are validated against independent mathematical oracles, never against the emu8086 implementation.
